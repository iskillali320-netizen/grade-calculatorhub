# Project: Grade Calculator Website

## Goal

Build a clean, modern, and SEO-optimized multi-page calculator website that is fast, mobile-friendly, and ready for AdSense approval.

## Design Rules

* Use modern SaaS UI style
* Soft gradient background
* Glass card components
* Clean typography (Inter / Poppins)
* Large spacing and breathable layout
* No clutter, no hard borders

## UX Rules

* Simple and intuitive interface
* Fast interaction
* Mobile-first design
* Clear input and output

## SEO Rules

* One page = one tool = one keyword
* Unique title and meta description for each page
* Use clear headings (H1, H2)
* Add helpful content (not fluff)
* Include FAQ section
* Add internal links between tools

## Code Rules

* Clean and readable HTML/CSS/JS
* No unnecessary code
* Fast loading performance
* Fully responsive

## Structure

* Homepage with tool cards
* Separate pages for each calculator
* Header with dropdown navigation
* Footer with legal pages

## Restrictions

* Do NOT add ads
* Do NOT use tab-based tools
* Do NOT mix multiple tools on one page

## Output Expectation

* Production-ready website
* SEO-friendly structure
* Clean UI/UX
* Easy to update content later
